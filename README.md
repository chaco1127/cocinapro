# CocinaPro

Aplicativo web de gestión de producción, ingredientes, recetas, planificación, dispatch, almacén y pedidos.

## Módulos
- Dashboard
- Ingredientes
- Recetas
- Planificación
- Dispatch
- Gestión de Almacén
- Gestión de Pedidos
- Data
- Resumen
- Actividad

## Funcionalidad actual
CRUD de módulos principales, filtros, movimientos de almacén, exportación/importación JSON, actividad y persistencia local con LocalStorage.

## Publicación
El sitio se despliega automáticamente en GitHub Pages mediante GitHub Actions.

## Próxima etapa
Conectar API REST, PostgreSQL/MySQL, autenticación, usuarios, roles y permisos para convertirlo en un sistema multiusuario empresarial.
